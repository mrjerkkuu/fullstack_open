# fullStackOpen

Tämä repositorio sisältää [Full Stack Open](https://fullstackopen.com/) -kurssin tehtävät ja tuntimateriaalit.

## Rakenne

Tehtävät on jaoteltu kurssin osien mukaan omiin kansioihinsa (`osa0`, `part1`, jne.), ja jokaisen osan sisällä tehtävät ovat omissa alikansioissaan.

Tuntimateriaalien mukana kirjoitetut esimerkkiprojektit löytyvät `tuntimatskut`-kansiosta, jaoteltuina samoin kurssin osien mukaan (esim. `tuntimatskut/osa1`).
